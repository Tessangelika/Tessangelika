## What I build

**[SAT Evaluator](https://github.com/Tessangelika/sat-evaluator)** — A Python CLI tool that scores security awareness quiz questions against a six-point quality rubric. Tells you not just whether a question is right, but whether it will actually build real-world recognition skills.

**[Threat-Aware Learner](https://github.com/Tessangelika/threat-aware-learner)** — ATT&CK-mapped security awareness scenarios, an interactive quiz, and an AI safety threat model of a real social sentiment analysis tool (Symbiont).

**[LXD Tools](https://github.com/Tessangelika/lxd-tools)** — Python scripts for learning designers: needs analysis generator, storyboard scaffold, and quiz exporter.

**[AI Literacy Curriculum](https://github.com/Tessangelika/ai-literacy-curriculum)** — Open curriculum for AI literacy, structured around scenario-based activities and clear learning objectives.
